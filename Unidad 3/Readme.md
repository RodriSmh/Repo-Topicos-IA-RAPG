# Carpeta Unidad 3
Contiene las carpetas de las tareas del modulo 3.

## Tarea 1
Es una investigación de la evolución diferencial la cual consiste en una presentacion del "¿qué es?" "¿cómo funciona?" y un ejemplo de como se aplica en pseudocódigo y en diagrama de flujo.
## Tarea 2
Es la implementacion de el algoritmo de enjambre de partículas, en este caso es una primera parte donde solo se aplicará la creación y inicialización de la particula y el ejambre.
## Tarea 3
Es la implementacion de el algorimo de enjambre, donde implementa las funcionalidades presentadas en clase
